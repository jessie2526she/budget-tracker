# 💰 記帳本 — 我的每月記帳

跟著「5 號發薪、信用卡月中結帳」的實際生活節奏記帳，把薪水分配到不同用途的帳戶（日常、儲蓄、信用卡…），清楚看到**這個月花了多少、存了多少**。純前端網頁，資料存在手機瀏覽器裡，可加到主畫面像 App 一樣使用，不需要帳號、不需要伺服器。

## 在手機上使用

### 方式一：GitHub Pages（推薦，網址可直接用手機開）

1. 到這個 repo 的 **Settings → Pages**
2. Source 選擇 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`
3. 儲存後幾分鐘會產生一個網址，例如 `https://<你的帳號>.github.io/budget-tracker/`
4. 用手機瀏覽器（iOS 用 Safari、Android 用 Chrome）打開這個網址
5. **加到主畫面**：
   - iOS Safari：分享 → 加入主畫面
   - Android Chrome：右上角選單 → 安裝應用程式 / 加到主畫面
6. 之後就可以像 App 一樣點圖示打開，離線也能用

### 方式二：本機開啟測試

```bash
python3 -m http.server 8000
# 用瀏覽器開 http://localhost:8000
```

## 核心邏輯：記帳週期跟著發薪日走

不是用日曆月（1 號～月底），而是 **每月 5 號 ～ 次月 4 號** 算一期，因為薪水 5 號才入帳，用日曆月會把「發薪前」跟「發薪後」的花費混在一起，看不清楚這次薪水到底夠不夠用。總覽頁可以用左右箭頭切換查看每一期。

## 帳戶（信封分帳法）

App 預設建立 4 個帳戶：🛒 日常、💰 儲蓄、💳 信用卡、🏠 固定支出，也可以在「帳戶」頁自行新增／刪除（有分配或交易紀錄的帳戶無法刪除，避免資料對不起來）。

## 分配薪水

發薪日當天，到「分配薪水」頁輸入薪水總額，再手動填入要分給各帳戶多少錢，畫面會即時顯示「尚未分配多少」，全部分完會顯示 ✅。每次分配都會留下紀錄，可以回頭查看或刪除。

## 記一筆：信用卡帳款怎麼記

信用卡通常是「這期刷卡、次月才扣款」。這個 App 的作法是：**扣款當天**才在「記一筆」新增支出，但把「算入哪一期」改選回上一期，這樣：

- 帳戶餘額：扣款當下才真的從「信用卡」帳戶（預備金）裡扣掉，符合實際現金狀況
- 消費分類：這筆錢的分類（餐飲／購物…）還是算進「上一期」的支出統計，才不會低估那期實際花了多少

「記一筆」的「算入哪一期」欄位預設會跟著你填的日期自動判斷，但一定可以手動改成上一期或下一期，不只信用卡可以用，任何想追溯記帳的情況都適用。

## 總覽：了解花了多少、存了多少

切到某一期後會看到：

- **本期收入 / 本期花費 / 本期存下**三個總覽數字（「存下」＝這期實際存入儲蓄帳戶的淨額，用實際入帳日期計算，跟信用卡的分類統計是分開兩套邏輯，各自反映對的東西）
- **支出分類**長條圖，一眼看出這期錢花在哪
- **帳戶餘額**，看到每個帳戶目前還剩多少（例如信用卡帳戶夠不夠付下期帳單）
- **本期明細**，列出這期所有交易，可以刪除

## 資料備份

資料存在「這支手機瀏覽器」裡（`localStorage`，key 是 `budget_data_v1`）。到「帳戶」頁下方可以「匯出 JSON」備份、「匯入 JSON」還原，換手機或清瀏覽器資料前記得先備份。
